# Design Context — Sauron

## Producto
Plataforma de video-analítica de tráfico (HPE GreenLake, edge GPU L4).
White-label: nombre, logos, favicon y colores se inyectan en runtime vía
`GET /api/v1/branding` — nunca hardcodear marca en componentes.

## Audiencia
- Operadores de tráfico en centro de control 24/7 (monitoreo live, alertas).
- Gestores/analistas (KPIs, conteos, velocidades, congestión).
- Ambos con igual peso: la home combina grid live + panel de alertas; analítica un click away.

## Tono / personalidad
- SOC oscuro: fondo oscuro tintado al color de marca (nunca negro puro),
  alta densidad de datos, jerarquía por severidad.
- Semáforo semántico: verde=info, ámbar=warning, rojo=critical.
- Tipografía: Space Grotesk (display), IBM Plex Sans (cuerpo), IBM Plex Mono
  (datos numéricos, IDs, timestamps). Fuentes bundleadas (@fontsource) —
  despliegue on-prem sin internet.
- UI en español.

## Constraints técnicos
- Vite + React + TS + Tailwind v4 + Recharts + lucide-react.
- WebSocket /ws/alerts con reconexión; ping de audio WebAudio en críticas.
- Todo detrás de reverse proxy same-origin (nginx): /api y /ws.
